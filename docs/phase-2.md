# Phase 2 — Fully dynamic authenticated application

## Completed

- Supabase SSR clients for browser, Server Components, Server Actions, Route Handlers, and Proxy
- Session-refresh Proxy using the Next.js 16 `proxy.ts` convention
- Sign-up, sign-in, sign-out, verification callback, forgot-password, and reset-password flows
- Protected application routes and safe internal redirects
- Complete PostgreSQL schema, ownership constraints, Row Level Security, indexes, triggers, and views
- Automatic profile and preference creation
- Dynamic Dashboard using authenticated records
- Tasks CRUD and completion workflow
- Skills CRUD and filtering
- Course, assignment, and calendar-event CRUD in Planner
- Persistent Study timer sessions, manual logging, editing, deletion, goals, and weekly totals
- Transaction and budget CRUD with live Finance calculations
- Notes CRUD, tags, pinning, favorites, course links, and search
- Deadline-derived Notifications with persistent read/delete state
- Cross-module record Search
- Persistent Profile and Preferences settings
- Light, dark, and operating-system theme support
- Dynamic unread-notification count
- Responsive desktop and mobile navigation to every visible module

## Deferred advanced features

- Syllabus unit/topic management
- Recurring-task occurrence generation
- Assignment and task subtasks
- Skill milestones and resources
- Reading-item and reading-log interfaces
- Habit tracking interfaces
- File and receipt uploads
- Push notifications, background jobs, and PWA/offline support

StudyFlow Dynamic Academic Tools — Windows setup

NEW INSTALLATION
1. Create a Supabase project.
2. Run supabase\phase2-complete.sql in the Supabase SQL Editor.
3. Double-click setup-studyflow-phase2.bat.
4. Enter the Supabase project URL and publishable key.
5. Keep the StudyFlow terminal window open.
6. Open http://localhost:3000

UPGRADING AN EXISTING STUDYFLOW PROJECT
1. Run supabase\phase3-academic-tools.sql once in the existing Supabase project.
2. Keep your existing .env.local file in the project folder.
3. Double-click DEPLOY-STUDYFLOW-TO-VERCEL.bat.

After the first local setup, double-click start-studyflow.bat to run the app again.

Node.js 20.9 or newer is required.
Never enter a Supabase service-role key in the setup file.

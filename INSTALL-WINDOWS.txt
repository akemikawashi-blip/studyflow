StudyFlow Dynamic Core — Windows setup

1. Create a Supabase project.
2. Run supabase\phase2-complete.sql in the Supabase SQL Editor.
3. Double-click setup-studyflow-phase2.bat.
4. Enter the Supabase project URL and publishable key.
5. Keep the StudyFlow terminal window open.
6. Open http://localhost:3000

After the first setup, double-click start-studyflow.bat to run the app again.

Node.js 20.9 or newer is required.
Never enter a Supabase service-role key in the setup file.

ONE-CLICK METHOD
================
1. Double-click START-HERE-STUDYFLOW.bat.
2. Follow each instruction shown in the window.
3. The launcher copies the database SQL, opens Supabase, creates .env.local,
   installs packages, and starts StudyFlow.
4. On future runs, double-click the same file again. Completed steps are skipped.
